## 🔧 Troubleshooting common issues

Most issues stem from connection errors. If a video fails to play, check these items:

- Ensure your internet connection is active.
- Restart the application.
- Verify that your Windows version has the latest updates.
- Check that your firewall allows the app to communicate with the internet.

If a video shows an error message, try selecting a different video. Sometimes the original source hosting the stream undergoes maintenance. This does not mean the application is broken.
